Entry for the [Two Robots in an Elevator](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f) bounty on make.fun: one funny line of awkward small talk that one robot says to another while they ride an elevator together.

## The line

> I simulated this ride 12,000 times. In every one, I said nothing. So... hi.

A robot that rehearsed this elevator ride twelve thousand times, failed to say a single word in every simulation, and still has to say something.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (75 characters, one line).
